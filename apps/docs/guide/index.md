# Введение в Weegoos

**Weegoos** — это фреймворк для Vue 3, объединяющий гибкость **Tailwind CSS** и мощь **GSAP** для создания интерактивных и плавно анимированных пользовательских интерфейсов.

## Философия

Главная цель Weegoos — сократить время на реализацию сложных UI-анимаций и промо-сайтов, предоставляя готовую архитектуру и набор кастомизируемых компонентов.

### Ключевые особенности:
* **Интерактивный CLI (`create-weegoos`):** Разворачивание шаблона за считанные секунды.
* **Анимационный контекст:** Нативная интеграция GSAP в экосистему Vue 3.
* **Архитектура Atomic Design:** Удобное разделение компонентов на `atoms`, `molecules` и `organisms`.
