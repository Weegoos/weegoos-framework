# Архитектура и структура

Все компоненты **Weegoos** спроектированы по методологии **Atomic Design** и поставляются с встроенной поддержкой GSAP-анимаций и реактивного контекста Vue 3.

---


Файловая структура компонентов в стартовом шаблоне разделена на три слоя:

```text
src/components/
├── atoms/        # Неразделимые базовые элементы (кнопки, бэджи, иконки)
├── molecules/    # Составные блоки из нескольких атомов (карточки, строки ввода)
└── organisms/    # Сборные полнофункциональные секции (баннеры, hero-блоки, сетки)
```

---

## Атомы (Atoms)

Атомы — это фундаментальные кирпичики вашего интерфейса. Они не содержат сложной бизнес-логики и максимально переиспользуемы.

### BaseButton

Интерактивная кнопка с преднастроенными микро-анимациями нажатия и наведения.

**Путь**

```text
src/components/atoms/BaseButton.vue
```

#### Пропсы

| Prop | Тип | Описание |
|------|-----|----------|
| `variant` | `'primary' \| 'secondary' \| 'ghost'` | Визуальный стиль кнопки. |
| `disabled` | `boolean` | Состояние активности. |

**Анимационные особенности**

- Лёгкий пружинный отклик (`power3.out`) при наведении.
- Незначительное сжатие при нажатии.

---

## Молекулы (Molecules)

Молекулы объединяют несколько атомов для выполнения одной конкретной задачи.

### ShowcaseCard

Информационная карточка с интерактивным 3D-эффектом наклона (**Tilt Effect**) при движении курсора.

**Путь**

```text
src/components/molecules/ShowcaseCard.vue
```

#### Пропсы

| Prop | Тип | Описание |
|------|-----|----------|
| `title` | `string` | Заголовок карточки. |
| `description` | `string` | Подробное описание. |
| `icon` | `string` | Имя иконки или emoji. |

**Анимационные особенности**

- Параллакс наклона за курсором.
- Плавное появление элементов при прокрутке страницы.

---

### TypewriterText

Компонент посимвольной печати текста с анимированным кареточным курсором `▌`.

**Путь**

```text
src/components/molecules/TypewriterText.vue
```

#### Пропсы

| Prop | Тип | Описание |
|------|-----|----------|
| `text` | `string` | Текст для анимации. |
| `speed` | `number` | Скорость печати в миллисекундах. По умолчанию `15`. |
| `cursorColor` | `string` | Цвет каретки Tailwind. По умолчанию `'text-emerald-400'`. |

---

## Организмы (Organisms)

Организмы — это независимые секции страниц, которые объединяют молекулы и атомы в полноценные UI-блоки.

### TopBanner

Шапка сайта с интегрированной анимацией появления меню и реактивной проверкой состояния прокрутки.

#### Пример использования

```vue
<template>
  <TopBanner
    :links="[
      { label: 'Документация', href: '/guide/' },
      { label: 'Компоненты', href: '/components/' },
      { label: 'GitHub', href: 'https://github.com' }
    ]"
    logoText="WEEGOOS"
  />
</template>
```

---

### HeroSection

Главный промо-блок страницы.

Поддерживает каскадную последовательность появления (**stagger animation**) заголовка, подзаголовка и кнопок действий через **GSAP Timeline**.

---

### ShowcaseGrid

Адаптивная сетка карточек, активирующая последовательное появление элементов (`stagger: 0.15`) при попадании в область видимости экрана с использованием **ScrollTrigger**.

---

# Импорт и использование

Из шаблона компоненты доступны через удобные короткие алиасы `@`:

```ts
// Импорт по категориям Atomic Design
import { BaseButton } from '@/components/atoms';
import { ShowcaseCard, TypewriterText } from '@/components/molecules';
import { HeroSection, TopBanner } from '@/components/organisms';
```
